# Equity-research

## Agentic AI Install Base Comparison

**`agentic_install_base_comparison.xlsx`** — A multi-sheet spreadsheet comparing the install base and adoption metrics for agentic browsers, AI coding tools, and AI assistants as of April 2026.

### Products Covered

| Category | Products |
|---|---|
| **Agentic Browsers** | Dia (The Browser Company), ChatGPT Atlas, Perplexity Comet, Microsoft Edge Copilot Mode, Opera Neon |
| **Agentic Coding Tools** | Claude Code (Anthropic), OpenAI Codex, GitHub Copilot, Cursor (Anysphere) |
| **Agentic AI Assistants** | OpenAI Operator / ChatGPT Agent, Microsoft Copilot (M365) |

### Spreadsheet Sheets

1. **Summary Comparison** — Side-by-side table of all products with user counts, paid subscribers, enterprise adoption, and growth metrics
2. **Agentic Browsers Detail** — Deep-dive on agentic browsers: launch dates, platforms, pricing, capabilities, and adoption indicators
3. **Market Context** — Macro market sizing, monthly platform traffic, and key milestones
4. **Sources & Notes** — All data sources and methodology notes

### Regenerating the Spreadsheet

```bash
pip install openpyxl
python3 create_spreadsheet.py
```
