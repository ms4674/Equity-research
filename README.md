# Equity Research

## Reports

- [Power Procurement Strategy for Data Centers: Hyperscalers and Neoclouds](power-procurement-strategy-data-centers.md) — Analysis of power procurement models, competitive positioning, and investment implications across hyperscalers (Microsoft, AWS, Google, Meta) and neoclouds (CoreWeave, Crusoe, Lambda) as power replaces compute as the primary constraint on AI infrastructure expansion. (May 2026)

- [Power-to-Tokens and Revenue Analysis: 1 GW Economics](power-to-tokens-and-revenue-analysis.md) — Quantitative analysis of the conversion from 1 GW of data center power to token generation throughput (~258 trillion tokens/year on B200) and GPU cloud rental revenue ($8-12B/year full-stack). Includes GPU count calculations, tokens-per-watt efficiency metrics, revenue sensitivity by business model, and the value multiplication chain from electron to API dollar. (May 2026)
