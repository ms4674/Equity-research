# Equity-research

## Uber Marketplace Metrics Comparison

Analysis of Uber's take rate and supply growth compared to other major marketplaces (Lyft, DoorDash, Airbnb, Instacart, Etsy, Booking Holdings).

### Files
- **`uber_marketplace_metrics_comparison.csv`** — Time series spreadsheet with take rates, gross bookings, revenue, supply-side metrics, and cross-marketplace benchmarks (2019-2024)
- **`uber_marketplace_analysis.md`** — Detailed written analysis with tables, commentary, and bull/bear arguments
